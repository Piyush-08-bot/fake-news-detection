## 📖 Overview

This project delivers an end-to-end classification and explanation workflow. It goes beyond simply labeling news as "Fake" or "Real" by utilizing a multi-stage LangGraph AI Agent to automatically reason over the text, fact-check claims against the internet, and provide human-readable explanations. 

- **Dataset**: ISOT Fake News Dataset (~38,646 articles)
- **First Pass (ML)**: TF-IDF Vectorization + Logistic Regression
- **Second Pass (AI)**: LangGraph state-machine orchestrating Groq LLMs and Tavily Search

---

## ✨ Features

### Fast & Reliable Machine Learning
- **Real-time analysis** from pasted text or URLs
- **Visual probability charts** and vocabulary density metrics
- **NLP insights** into top influential words guiding the model's decision

### Explainable & Interactive Agentic AI
- **Tone & Domain Identification**: Categorizes the emotional mood (e.g., sensational, urgent) and topic (e.g., politics, finance).
- **🚩 Suspicious Text Highlighting**: Extracts clickbait, emotional triggers, and unverified numbers into color-coded hover pills.
- **📋 Claim Breakdown**: Automatically splits the article into distinct factual claims with individual ✅ / ❌ / ❓ verdicts.
- **🔍 Automated Web Verification**: The AI agent actively searches the web via Tavily to cross-reference claims against trusted sources.
- **⚖️ Article Comparison Tool**: Paste a second article to see a side-by-side credibility comparison generated by the AI.
- **💬 Interactive AI Chat**: A persistent follow-up box to ask the AI agent direct questions about its analysis without losing your current results.

---

## 🎯 The Problem We Solve

In an era of rapid information spread, determining the credibility of news is increasingly difficult. While classical models can detect vocabulary patterns associated with clickbait, they fail to provide **explainability** or **fact-checking**. 

This engine solves that by treating classical ML as a lightning-fast "triage" step, and an AI Agent as the "investigator". It provides users with extreme transparency, letting them see exactly which phrases are suspicious, which claims are unverified, and what trusted web sources actually say.

## 🚀 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Piyush-08-bot/fake-news-detection.git
   cd fake-news-detection
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure API Keys (for AI features):**
   Copy the example environment file and insert your free keys.
   ```bash
   cp .env.example .env
   ```
   *Get free keys from [Groq Console](https://console.groq.com) and [Tavily](https://tavily.com).*

4. **Run the Dashboard:**
   ```bash
   streamlit run app.py
   ```

*(Optional) Install Jupyter to view the training notebook:*
```bash
pip install ipykernel jupyter
jupyter notebook News_Credibility_Training.ipynb
```

- URL extraction uses standard requests. Some sites block scraping or return insufficient text.
- The classical ML pipeline detects linguistic patterns and word choices, whereas the AI Agent performs logical reasoning and active fact-checking. Both are signals, but *not* definitive arbiters of truth. 
- **Disclaimer**: This tool is for educational purposes only. It does not replace professional fact-checking for real-world news events.
